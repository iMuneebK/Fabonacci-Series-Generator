# Fibonacci Series Generator & Complexity Benchmark

[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Algorithms](https://img.shields.io/badge/Algorithms-DP%20%7C%20Matrix%20Exponentiation-green.svg)](#algorithms)

High-performance Fibonacci series computation suite demonstrating dynamic programming, iterative pipelines, matrix exponentiation $O(\log n)$, and closed-form Binet approximation with precision benchmarking and interactive visualizer.

## Key Features
- **Iterative Generator**: Memory-efficient space-optimized $O(n)$ time and $O(1)$ auxiliary space.
- **Dynamic Programming (Memoization)**: Top-down recursive approach caching intermediate subproblems.
- **Fast Matrix Exponentiation**: Logarithmic $O(\log n)$ matrix binary powering for astronomical term values.
- **Binet Analytical Closed Formula**: Direct float evaluation utilizing the golden ratio.
- **Microsecond Benchmarking**: Built-in comparative performance timers.

## Quick Start
```bash
git clone https://github.com/iMuneebK/Fabonacci-Series-Generator.git
cd Fabonacci-Series-Generator
python fibonacci.py --terms 20
```
